1️⃣ React est une librairie et non un framework
React ne fournit que le minimum :

Rendu des composants (useState, useEffect...)
Mise à jour du DOM de manière optimisée
Il n'impose pas de système de routage, de gestion des formulaires, ou de graphiques. C'est à toi d'ajouter ce dont tu as besoin.

la difference entre ts et tsx 
.ts Files: These are standard TypeScript files used for writing code that doesn't involve JSX. 
They are suitable for defining functions, classes, interfaces, and other TypeScript constructs.

.tsx Files: These files are an extension of .ts and are specifically designed to support JSX syntax. 
JSX allows developers to write HTML-like code within JavaScript or TypeScript, which is particularly useful when working with React components.
